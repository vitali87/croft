fix: Toggle Block Comment keeps the line's indentation, and no longer pulls the next line into the comment when a whole line is selected.
fix: Sort Lines no longer leaves the cursor past the end of a shorter line, which crashed croft on the next word jump.
fix: Move Line Up/Down and Sort Lines unfold the lines they move. A fold used to keep hiding the same line numbers over different text.
fix: when an edit brings two cursors to the same spot, they become one. The next key used to apply twice, so one Backspace could delete two line breaks.
fix: pasting text with Windows (CRLF) or old Mac (CR) line breaks splits it into lines. A stray carriage return used to stay inside each line and was saved as an extra `\r`.
fix: Replace in the find bar replaces a whole-word match that starts or ends with punctuation, such as `$var` or `@user`. It used to jump to the match without replacing it.
fix: Join Lines, Sort Lines, case changes, Trim Trailing Whitespace, the comment toggles, Duplicate and Move Line, and Increment/Decrement Number clear extra cursors instead of leaving them on the wrong rows.
