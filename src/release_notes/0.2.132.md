feature: Show or Focus Hover (`Ctrl+K Ctrl+I`, `Cmd+K Cmd+I` on macOS) opens the hover for the symbol at the caret from the keyboard: its type and docs, and the full message of a problem there. It is in the Command Palette, and `croft import-vscode` carries over a chord bound to VS Code's `editor.action.showHover`.
fix: `Ctrl+K Ctrl+I` in the editor no longer toggles Broadcast Input; `Ctrl+K I` still does.
fix: Hovering a word with a problem in a file no language server has shows the problem's message.
feature: A diagnostic's related locations ("immutable borrow occurs here", "'foo' is declared here") show in its hover and as rows under it in PROBLEMS; click one to go there.
feature: Git: Open Commit for Line opens the change the caret line's commit made to the file, and so does a click on the inline blame.
feature: Git: Copy Commit Hash for Line copies the full hash of the caret line's commit.
feature: Resting the mouse on the inline blame shows its commit's author, email, date, hash and whole message.
