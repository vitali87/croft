feature: Session: Detach (`Cmd+K Shift+Q`) leaves a persistent session (`croft attach`, `croft remote`) while it keeps running; before, closing the terminal window was the only way out. The attach client catches the chord itself, so a read-only participant or a client of an unresponsive session can always leave. On the way out, whether it detached or was disconnected from Session: Participants, the client puts the terminal back as croft's own exit does (no alternate screen, mouse reporting or enhanced keys left on) and says whether the session is still running. `Cmd+K D` stays Dump Scrollback.
