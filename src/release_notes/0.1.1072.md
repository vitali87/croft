feature: the status bar names the kernel of the notebook in the editor once it is up, with "busy" while a cell runs.
feature: a terminal recording (Session: Record Terminal as Asciicast) shows its own CAST badge in the status bar with how long it has run, apart from the macro recorder's REC.
feature: in the history scrubber, Enter at a commit opens that version of the file as a tab of its own. Source Control: Diff Scrubbed File to Working Tree diffs it against the file on disk.
feature: Debug: Install Go Debugger (delve) runs `go install` for delve in a terminal pane, into `~/.croft/servers/go`. When delve is missing, the message says whether Go is installed to build it with.
feature: each Agent Lane file row shows how many lines were added and removed since you last reviewed it.
feature: clicking the ● on an Agent Lane row marks that file reviewed; clicking its name still opens the diff.
feature: `croft demo --tour <file>` runs your own tour steps (same shape as the built-in tour) in the sample project, and refuses a file that is not a tour.
feature: an open pull request review re-reads its checks every 30 seconds while any is still running, and says when the last one finishes.
feature: after a coverage run, the Testing summary shows the overall percentage covered, and Testing: Show Coverage Report opens a tab listing each file with its percentage, least covered first.
feature: Source Control: Review Pull Request lists the repository's open pull requests to pick from; the last row still takes a number or URL.
feature: a terminal recording masks secrets the way the screen does (keys and tokens are recorded as •••), and revealing them on screen does not reveal them in the cast.
feature: Testing: Run Test at Cursor with Coverage runs only the test the caret is in under the coverage tool, so the report shows what that test reaches.
feature: while debugging a program with several threads (goroutines under delve), CALL STACK lists each one with the selected thread's frames under it. Clicking another thread shows its stack, and stepping then applies to it.
feature: the history scrubber has a slider along the bottom of the editor showing where you are in the branch's history. Click or drag it to move between commits.
feature: in the agent approval popup, `a` approves the edit and every edit from the same agent for the next 10 minutes, with a countdown in the status bar. Agents: Stop Auto-Approving ends it early.
feature: a fleet run opens its results as tiles in a Fleet tab: one per host, with a status dot and its time, and only the lines that differ from the most common output (or from the tile you pick with `r`). `s` saves the whole run to a file, and Enter opens a shell on the selected host.
