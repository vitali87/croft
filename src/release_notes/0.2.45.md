fix: Scrub History follows a renamed file back past the rename, like TIMELINE and blame: commits before a `git mv` show the file under its old name (named in the scrub bar, e.g. `2/4 · old.py`) instead of "did not exist", and the rename commit no longer marks every line as added.
fix: F5 on a C or C++ file in a configured CMake project now builds the project and debugs the executable that compiles the file, instead of compiling that one file alone with bare `c++`; without CMake, a `compile_commands.json` entry supplies its include paths and flags. The build runs in the background, a failed build keeps its whole output in OUTPUT › Debug Build, and nothing is written next to the source.
fix: A file you can't write shows a lock on its tab and "Read-only" in the status bar as soon as it opens. Saving your own write-protected (`chmod 444`) file now asks first, and a second Cmd+S overwrites it and puts its permissions back. When a save fails with "permission denied", the next Cmd+S (or File: Save with Sudo) writes the file through `sudo tee` in a terminal pane, where sudo asks for your password, and the tab turns clean once the file is written.
fix: In a folder with tests in two languages, such as a maturin crate (Cargo.toml and pyproject.toml) or a Python backend with a JS frontend, the Testing view lists both runners' tests, and Run or Debug Test at Cursor uses the runner for the file's language instead of the first one found.
feature: Browser JavaScript and TypeScript can be debugged: launch.json `chrome` and `msedge` configs (and their `pwa-` forms) run on croft's bundled js-debug instead of being refused as an unsupported type, and with no display the browser runs headless.
fix: `croft import-vscode` keeps a keybinding's editor or Explorer `when` scope and reports terminal-only or compound conditions instead of turning them into global bindings, and a key chord in `keybindings.json` honours `"when": "editor"` and `"when": "file_tree"`
fix: With `trim_trailing_whitespace` in .editorconfig, Cmd+S, Save All and the other explicit saves now trim the line you just edited too; only auto-save leaves the caret line for later.
fix: A paste made while recording a keyboard macro is now part of the macro: replaying it pastes the same text at the new caret instead of silently leaving it out.
fix: Running a README `console` fence (or a shell fence written as a transcript) now runs only its `$ ` commands, without the prompt; its sample output is never typed into the shell.
feature: A repository's own snippets now expand: croft loads every `.vscode/*.code-snippets` file (VS Code's project snippets) and `.croft/snippets.json` in each workspace folder, after your own `snippets.json` so your snippet wins a prefix both define, and picks up changes to them while it runs (#1484).
fix: Running one jest or vitest test from the TESTING view now runs only that test: its full name is matched exactly, and jest runs only that exact file, not same-named files elsewhere or tests whose names merely contain its title.
feature: Column rulers: the `rulers` setting (for example `[80, 100]`) draws a dim line down the editor at each column to show a line-length limit, a repository's `.croft/config.json` may set it, and `editor.rulers` from `.vscode/settings.json` and `croft import-vscode` carries over.
feature: Debug: Step Into Target picks which call on the paused line to step into, as in VS Code: on `transform(load(p), scale(2))` it lists the three calls and enters the one you choose. Continue, Step Into and Step Out are now commands too (`continue`, `step_into`, `step_out`), so the Command Palette finds them and `keybindings.json` can rebind them.
feature: Emmet can now edit markup already written, as in VS Code: **Emmet: Wrap with Abbreviation** wraps the selected lines (or the element around the cursor) in an abbreviation such as `nav.menu`, with `ul>li*` putting each line in its own `li`; **Remove Tag** takes away the tags around the cursor and moves their content out a level; **Update Tag** renames both tags; **Go to Matching Pair** jumps between an opening and closing tag; and **Balance (outward/inward)** grows or shrinks the selection one element at a time. Imported VS Code keybindings for these commands map across (#1557).
fix: Translations now reach the side bar and panel titles (EXPLORER, OUTLINE, PROBLEMS, OUTPUT, TERMINAL and the rest), the Command Palette title and the unsaved and discard prompts, and `croft locale-template` lists them.
fix: Screen reader mode now reads a dialog when it opens, with what it says and which key does what: Unsaved Changes on close or quit, Discard Changes, Discard All, Revert Hunk, Replace All, Run Block, Broadcast Input, Open on Local Mac, an agent's edit approval, the Settings editor and every one-line prompt with its field's instruction. A long path or command is shortened so the keys are always read. Before, they were silent and the caret line behind them stayed on the status bar.
fix: Language server errors, questions and links now reach you. An error or warning a server sends, such as rust-analyzer's "Failed to load workspaces" for a broken Cargo.toml, shows on the status line instead of only in OUTPUT. A server's question opens a picker of its answers (Esc answers none), and a document or link it asks to show opens in a tab or the browser, so gopls's "Browse documentation" quick fixes now open the page. A quick fix that only runs a server command now says "Ran …" rather than "Applied quick fix".
fix: One-line prompts such as Save Workspace As and Rename Branch now open with a prefilled value selected, so typing or pasting replaces it. Ctrl+A selects it again, Ctrl+U and Ctrl+K clear to the start or end, and Ctrl+W, Alt+Backspace and Ctrl+Backspace delete a word back to the previous space or path separator. A value wider than the box scrolls to keep the caret in view.
fix: Applying a quick fix or rename that adds or changes text above the caret, such as Add import, now keeps the caret, the selection and every extra caret on the text they were on, so typing straight after the fix no longer lands in the import block.
fix: An inline AI suggestion that runs over several lines now shows every line under the caret before Tab takes it, where a body after `def …:` showed only "(+2 lines)". Ctrl+Right takes its next word and Ctrl+Down its next line, keeping the rest.
fix: The hex editor's Find can now search for text that looks like hex, such as "1234", "2024" or "cafe": put it in double quotes, or search from the text column (Tab), and it is found as text. The status line says which was searched for, `Found bytes 12 34 at 0x11A` or `Found text "1234" at 0x115`.
feature: Fold Level 1–7 (`Cmd+K Cmd+1` … `Cmd+K Cmd+7`) collapse every fold that deep or deeper for an overview of a large file, and Fold Recursively / Unfold Recursively act on the fold at the cursor and every fold inside it.
feature: The Settings editor resets a setting with Del, removing it from the layer's file so the value falls back to the layers below or croft's default, and marks every setting changed from the default with a dot.
fix: `croft` typed in croft's terminal is the croft you are running. Another install earlier on PATH, such as a Homebrew croft that `brew shellenv` puts first, no longer answers instead, so `croft --version` in a pane matches the version on the welcome page.
feature: Panes running macOS's built-in bash 3.2 get croft's shell integration (command navigation, command decorations and cwd tracking), as bash 4.4 and later already did.
