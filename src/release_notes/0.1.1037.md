fix: Find and Replace no longer crashes, and no longer replaces the wrong text, on lines with characters whose lowercase form has a different length (`ẞ`, `İ`, the Kelvin sign). Matching ignores case by default, so these lines were hit without any option set.
fix: in a regex replacement, `$1_old` puts back group 1 followed by `_old`, as in VS Code. Before, it deleted the match, because it was read as a group named `1_old`.
fix: Replace All across the workspace in regex mode honours `^` and `$` at line ends, including on CRLF files, so it replaces every hit the preview lists instead of only the first one or none.
fix: on Linux, changes to files in folders created after croft started (a `mkdir`, a `git checkout`, a rebuilt `build/` folder) now show up in the changed-files list, and those folders are watched from then on.
fix: the session roster no longer shows a participant who has left, or nobody at all, when two clients join, leave or resize at the same moment.
fix: a saved `.code-workspace` whose own folder path goes through a symlink no longer points a relative folder entry at the wrong directory. When the relative path would resolve somewhere else, the folder is saved as an absolute path.
