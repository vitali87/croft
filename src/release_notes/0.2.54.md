fix: Language server, debugger, theme and update downloads work behind a TLS-inspecting corporate proxy: croft now goes through HTTPS_PROXY (honouring NO_PROXY) and trusts the system's certificate store and SSL_CERT_FILE as well as its built-in roots.
fix: A failed language server download says why in the status bar and in OUTPUT › Server Provisioning (an HTTP status, a refused connection, a timeout or an untrusted certificate) instead of only "download error".
fix: `croft ls` no longer lists a phantom "(unknown)" session for each open croft window.
fix: On Linux, right-click menus and the Customize Layout popup name shortcuts as you press them there (Ctrl+B, Ctrl+Alt+M) instead of with the Mac's ⌘ and ⌥ keys.
fix: A tab character takes a cell in the editor, the diff view and the merge editor, so text after a tab no longer slides left under the caret, the selection and the whitespace markers, and tab-indented code is no longer drawn flush-left.
fix: A file deleted on disk while open no longer pins "Reload failed" in the status bar and hide every other message: croft says once that it was deleted, marks its tab "(deleted)", keeps the text, and the next save recreates it.
fix: Unsaved edits to a file deleted on disk no longer open the "changed on disk" prompt or need a second save to write.
fix: `Ctrl+G` `25` `Enter` (VS Code's Go to Line) jumps to line 25 instead of inserting a newline, and a key that cancels a `Cmd+g` or `Cmd+y` chord after a count no longer edits the buffer.
fix: Opening a conflicted file you already resolved by hand in the merge editor keeps your resolution instead of resetting it to the base text, and Complete Merge stages it.
fix: A partly resolved conflicted file opens in the merge editor with its resolved blocks and other edits intact, asking only about the conflicts still marked.
fix: Language servers now hear about files changed on disk outside a tab, so Go to Definition works right after a cross-file Rename, a git checkout or an agent's edit.
fix: In the editor, Ctrl+Left/Right move by word (with Shift, select by word) and Ctrl+Home/End go to the start or end of the file, as in VS Code on Linux; they used to move one character or stay on the line.
feature: Ctrl+Backspace and Ctrl+Delete (Option+Backspace and Option+Delete on macOS) delete the word left or right of the caret.
fix: Format Document and Format on Save no longer add a blank line at the end of a file that is already formatted: language servers now see the file's final newline, so ruff, rustfmt, rumdl and other formatters leave it alone and linters stop reporting a missing newline.
fix: A terminal pane whose shell exits (`exit`, Ctrl+D) now closes instead of staying open, dead and swallowing input, and its shell no longer lingers as a zombie process. The last pane stays with "[Process exited with code N]" until you press a key, which starts a new shell.
fix: A task that ends its shell, such as `make test || exit 1`, now reports its exit code instead of showing "Running" for good, and its pane stays open so you can read the output.
fix: Text typed with several cursors undoes in one Ctrl+Z, as it does with one cursor, and the cursors and selections come back.
fix: Snippet variables such as `$TM_FILENAME`, `$CLIPBOARD`, `$CURRENT_YEAR` and `$UUID` now expand to their values, as in VS Code, instead of being inserted as literal text; `${VAR:default}` falls back to its default, and an unknown variable becomes a placeholder you can type over (#914).
feature: Copy Line Up/Down, Trigger Suggest and Trigger Parameter Hints are commands: they are in the Command Palette and can be bound in keybindings.json (copy_line_up, copy_line_down, trigger_suggest, trigger_parameter_hints).
fix: croft import-vscode carries over bindings for Toggle Word Wrap, Toggle Minimap, Copy Line Up/Down, Peek References (editor.action.referenceSearch.trigger), Peek Call Hierarchy (editor.showCallHierarchy), Trigger Suggest and Trigger Parameter Hints instead of reporting that no croft command matches.
fix: croft import-vscode --from pointed at the VS Code folder (~/.config/Code) reads its User folder instead of importing nothing.
fix: `croft pr` without the GitHub CLI, or with gh signed out, says so in the shell and how to fix it, instead of opening an editor whose review never loads.
fix: PR review, review comments, code scanning and CodeQL's GitHub databases and variant analysis name a missing or signed-out GitHub CLI and how to fix it, instead of "No such file or directory (os error 2)".
fix: When a collaborator or a quick fix adds or removes lines above the part of a file you are looking at, the view stays on the same text instead of sliding up or down.
fix: In a `--solo` session Ctrl+Z undoes only your own edits and keeps what your collaborator typed since, instead of removing their latest change first.
fix: A runnable shell block of several lines runs as one command, so the box under it (and its `{persist}` copy) shows the output of every line and the exit code the block ends with, not just its first command's.
fix: Search & Replace from Last grep/rg matches case the way the command did (grep, rg, git grep and ack only ignore case with -i; -S and ag use smart case), so Replace All no longer rewrites differently-cased lines the terminal never listed.
fix: A `config.json` with a syntax error is named on the status line at startup, with the line to fix, instead of every setting quietly reverting to its default.
fix: A setting changed while `config.json` cannot be read or parsed says "Setting not saved" and why, instead of confirming a change that is lost on restart.
