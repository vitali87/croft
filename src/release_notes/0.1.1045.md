feature: `croft web` takes `--tls CERT KEY` for wss://, serves a non-loopback `--bind` with a warning, and stops when its session ends. `croft web --off` stops it, `--rotate-token` restarts it with a new token, and `croft ls` shows where each session is served. The token now travels as a WebSocket subprotocol instead of in the URL.
