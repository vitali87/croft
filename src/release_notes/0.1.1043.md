fix: opening a truncated or malformed MP3 or MP4 file no longer crashes croft, which used to lose every unsaved buffer.
security: the folder that holds a remote connection's SSH control socket is created fresh and readable only by you. It used to have a predictable name in the shared temp folder, and croft accepted it even if another user on the machine had created it first.
fix: review comments and Submit Review no longer freeze croft while asking GitHub for the pull request number. The number is reused from the review already loaded, and a lookup that hangs gives up after 5 seconds.
fix: runnable code blocks in the markdown preview that contain a tab or `!` run exactly as shown. A tab used to trigger the shell's completion, so indented Python lost its indentation, and bash expanded `!` as a history reference.
fix: opening an image reads only its header to size the tab instead of decoding the whole picture, so large photos open faster and images past the decoder's memory limit open at all. The markdown preview skips images over 25 MB or 64 megapixels.
fix: markdown images whose path uses URL escapes (`Screen%20Shot.png`) or carries a query (`img.png?raw=true`) now show in the preview.
fix: the command palette, Quick Open, the other pickers and the confirm dialogs no longer crash croft on a terminal narrower than about 50 columns or shorter than 10 rows, such as a phone in portrait or a small tmux split.
fix: opening a named pipe (FIFO), socket or device, for example by clicking it in the Explorer, no longer freezes croft. It says the path is not a regular file.
fix: opening a large SQLite database no longer freezes croft while it counts every row of every table. Each table shows its first page and says when more rows follow.
fix: accepting a completion applies the language server's own edit, so TypeScript's optional chaining gives `a?.foo` instead of `a.?.foo`, and auto-imports (Python, C/C++ `#include`) are added with the completion. Snippet completions sent only as an edit insert their full body.
fix: search-panel Replace All with a zero-width regex such as `^` or `$` inserts at every line again, and a whole-word regex with alternatives (`foo|foobar`) replaces every match the search listed. Replace now uses the same matcher as the search.
fix: Replace All keeps a hard-linked file linked and keeps the owner of a file that belongs to someone else, by writing those files in place.
security: in a `tasks.json` command written as a shell line, such as `python3 ${file}`, the file path is now quoted, so a file name containing spaces or `;` stays one argument and can't run a command.
fix: `tasks.json` commands that use variables croft doesn't expand, such as `${HOME}` or `${input:...}`, run again and leave them for the shell; an unset `${env:X}` is empty, as in VS Code.
fix: a self-update relaunch keeps unsaved edits in every split, not just the focused one.
fix: a secret whose separating space falls at a soft wrap is masked in the saved terminal transcript and scrollback dump, as it already was on screen.
fix: merge-commit diffs no longer show the second and later files' headers as changed lines.
fix: while a push, pull or fetch runs in the background, other Source Control actions and branch switches wait instead of fighting over the repository, and a finished clone no longer pulls you out of a folder you switched to meanwhile.
fix: Fleet Run keeps a host's output when the command leaves a background process running.
fix: saving one setting inside a settings object keeps unknown keys nested in that object, and a removed entry leaves the file.
