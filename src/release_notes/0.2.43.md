fix: `Ctrl+Enter` (`Cmd+Enter` on macOS) is Insert Line Below, as in VS Code: with the caret mid-line it opens an indented line under the current one instead of splitting it. In a Markdown fence it still runs the block, and `Ctrl+O` stays an alias. "Insert Line Below" and "Insert Line Above" are now palette commands (`insert_line_below`, `insert_line_above`), and VS Code's `editor.action.insertLineAfter` / `insertLineBefore` keybindings import onto them.
