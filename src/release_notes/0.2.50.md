fix: A `tsc: build - <file>` task detected from a tsconfig is waited for until its build finishes when it runs as a `preLaunchTask`, as any task that is not a background task is.
feature: launch.json and tasks.json `${input:…}` variables work: croft reads the file's `inputs` and asks for each one once when the configuration or task starts, with a pick list for `pickString` (its default selected), a text box for `promptString` (prefilled, masked for `password`), and the answers shared with the preLaunchTask and a compound's members; Esc cancels quietly, and an id no `inputs` entry declares is named in the error.

VS Code keybindings for `editor.action.transformToSnakecase` and the other three now import.
feature: `files_associations` (VS Code's `files.associations`) picks the language a file opens in by glob, in user or workspace config: `{ "*.tpl": "html", "**/templates/*.txt": "html" }`.
