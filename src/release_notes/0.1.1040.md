fix: changing a setting from inside croft (theme, keyboard split, disabled extensions, and others) no longer deletes `extends`, the `macos` / `linux` / `android` blocks, or settings from newer versions in `config.json`. Only the setting that changed is rewritten.
fix: a comment or trailing comma in `config.json` no longer makes croft ignore the whole file. Before, disabled language servers and debuggers were enabled again.
fix: recording a keyboard shortcut no longer replaces a `keybindings.json` that croft cannot read or parse with that one binding. It says the file needs fixing and leaves it alone.
security: the drag-and-drop relay no longer sends a hidden file (such as anything under `~/.ssh`, `~/.aws` or `~/.gnupg`) or a link to one when a remote host asks for it, and a folder it sends leaves its hidden files and folders behind. Any process on the remote could make that request. A dropped file whose name starts with `-` is also sent correctly.
fix: Fleet Run no longer times out and loses all output when a command prints more than about 64 KB.
fix: the diff view shows a removed line that starts with `--`, such as an SQL, Lua or Haskell comment. It was hidden as if it were a file header.
fix: jumping from a multi-file diff to the file works for paths with non-ASCII characters, and for paths containing ` b/`.
fix: tasks from `.vscode/tasks.json` expand `${workspaceFolder}`, `${file}` and the other variables, keep an argument with spaces as one argument, and honour `options.cwd` and `options.env`. A path a variable fills in is always quoted, so a file or folder name with `'`, `;` or `$` in it cannot run as a command. A task that uses `${file}` with no file open says so instead of running.
fix: saving an edited CSV or TSV file keeps its CRLF line endings.
fix: editing an xlsx cell to `02134` keeps the leading zero, and text like `nan`, `inf` or `1e400` is stored as text. Before, these became numbers, and the last three made Excel report the file as corrupt.
fix: push, pull, sync, fetch, publish and clone run in the background, so a slow remote or a large clone no longer freezes croft. A remote that asks for a password or passphrase fails with a message instead of taking over the screen.
fix: blank lines in a CSV or TSV survive a save. A single-column file used to lose every empty value.
fix: Timeline entries from before a file was renamed open the diff that commit made, instead of an empty one.
security: secret redaction masks a secret that a soft wrap splits across two terminal rows, on screen, in the saved terminal transcript and in the scrollback dump. A GitHub token or JWT near the right edge of a pane used to show in full.
fix: one bad row or a trailing comma in `triggers.json` no longer turns off every rule you wrote, redact rules included. Bad rows are skipped, and the reload status says how many. `agents.json` also skips bad rows now.
fix: a self-update relaunch is cancelled if croft cannot save the session first, so unsaved text is never lost. The handoff file is readable only by you, and one that fails to load is kept instead of deleted.
fix: sticky notes added in two windows on the same workspace are both kept, and a notes file that fails to parse is moved aside instead of being overwritten.
fix: a `.http` response with a repeated header, such as two `Set-Cookie` lines, shows every value.
fix: an MCP server that writes a lot to stderr no longer stops answering, and finished MCP servers no longer linger as zombie processes.
