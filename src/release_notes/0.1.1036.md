fix: an Explorer move that fails, such as a folder dropped into its own subfolder, no longer rewrites imports in other files to point at the path it never reached. When a move succeeds, import updates for files inside the moved folder are written at their new location.
fix: a rename or quick fix that lands while you type in a symbol tab is no longer undone by your next keystroke.
fix: Peek References on a file with no language server (or an unsaved buffer) no longer makes the next Go to References open in the peek popup.
fix: a Keyboard Shortcuts prompt ends when you click elsewhere or after 15 seconds, so a later Cmd+S saves instead of being bound to the command you picked.
fix: in the terminal, Right arrow no longer types a suggestion that went stale while keys were still being echoed (`gi` + Right giving `giit status`).
fix: loading a PR's review comments and opening Export Comments to Pull Request no longer freeze croft while `gh` talks to GitHub. Both now run in the background, and the status bar says when they finish. A failed reply or failed comment load no longer lets a second review submission start while the first is still posting.
fix: typing `>` in HTML, XML or JSX no longer adds a second closing tag when the element is already closed (retyping a deleted `>` in `<div</div>`).
fix: with several cursors on one line, each keystroke now lands at every cursor. The second keystroke used to go to the wrong column for cursors to the right of another (`abcd` with cursors at 1 and 3, then X, Y, gave `aXYbcYXd`).
fix: `croft locale-template de_DE` (or `de-DE`, or `de_DE.UTF-8`) now seeds the template from the built-in German catalog and names the file to save, `locales/de.json`, instead of printing an empty template for a file croft never loads.
fix: `croft hook install` and `--uninstall` write Claude Code's `settings.json` to a temporary file and rename it into place, so an interrupted write can't truncate your settings.
