fix: an Explorer move that fails, such as a folder dropped into its own subfolder, no longer rewrites imports in other files to point at the path it never reached. When a move succeeds, import updates for files inside the moved folder are written at their new location.
fix: a rename or quick fix that lands while you type in a symbol tab is no longer undone by your next keystroke.
fix: Peek References on a file with no language server (or an unsaved buffer) no longer makes the next Go to References open in the peek popup.
fix: a Keyboard Shortcuts prompt ends when you click elsewhere or after 15 seconds, so a later Cmd+S saves instead of being bound to the command you picked.
fix: in the terminal, Right arrow no longer types a suggestion that went stale while keys were still being echoed (`gi` + Right giving `giit status`).
