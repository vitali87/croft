fix: Deleting from the Explorer asks a plain Y/N question: N or Esc keeps the file, where typing "no" into the old text box and pressing Enter still moved it to the Trash.
fix: The uninstall, CodeQL remove, remote tag delete and extension consent questions answer to Y/N as well, with no text field to type a different answer into.
fix: In Source Control, Tab or Down moves from the message box into the change list, where arrows select a file, Enter opens its diff, Space or S stages, U unstages and D discards it.
feature: Git: Commit, Push, Pull, Sync, Checkout to… and Stash are in the Command Palette, so the Source Control menus' actions need no mouse and can be bound to keys.
fix: Find matches, selections, bracket colours, squiggles and other editor highlights land on the right characters after CJK text or emoji instead of shifting left.
fix: Commands that clear the screen, such as `clear; make` or `reset; cargo test`, are now kept in the command history (Ctrl+Shift+H), and their build errors reach PROBLEMS.
fix: A command that clears the screen is no longer recorded in the history as the command run before it.
fix: A notebook kernel that fails to start no longer wipes the cells' saved outputs or leaves them stuck at In [*], and the next run starts a new kernel, so installing ipykernel works without relaunching croft.
fix: Notebook: Restart Kernel starts a new kernel when the old one has stopped, instead of doing nothing.
fix: An idle croft settles down instead of re-reading the folder tree and re-running git several times a second, which kept a core busy on large workspaces.
fix: croft no longer trusts the eMudhra root certificate whose intermediate CAs had their private keys leaked. Someone on your network could have used those keys to read the API key sent for inline completion or pair, or to swap a language server or debugger croft downloads.
