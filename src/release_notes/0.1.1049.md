fix: undo history in a large file is capped at 256 MB per tab, dropping the oldest steps first while always keeping the last 16. Every step holds a copy of the file, so 500 steps of a 10 MB file could take 5 GB (part of #694).
fix: the OUTPUT panel keeps at most 16 KB of any one line, so leaving language-server RPC tracing on no longer holds thousands of multi-megabyte messages, and diagnostics for files no server reports on any more are dropped instead of kept for the whole session (part of #694).
fix: `~/.croft/lsp.log` starts over past 8 MB, keeping the previous log as `lsp.log.1`, instead of growing for as long as croft is used.
fix: when a Linux host runs out of memory, the kernel now stops croft's language servers, and a self-build on a remote host, before croft itself, so the shells and jobs in your terminal panes survive. A language server stopped this way stays off until you relaunch croft or reopen the workspace (part of #694).
fix: clicking the same localhost link from a remote session no longer opens a new browser tab at a new random 127.0.0.1 port each time; croft reuses the port it already forwarded (#648).
fix: on Linux, terminal panes get a UTF-8 locale when the inherited one isn't (such as the `LC_CTYPE=UTF-8` macOS sends over ssh), so shell prompts with symbols like `❯` no longer leave coloured two-character leftovers behind (#537).
