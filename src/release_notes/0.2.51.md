feature: Column (box) selection works from the keyboard. Ctrl+Shift+Alt+arrows (Cmd+Shift+Opt on macOS) and +PageUp/PageDown grow a box one row, column or screen at a time, so typing edits the same columns of every line, and View: Toggle Column Selection Mode makes plain Shift+arrows do the same. These chords used to add a single caret and then select the whole line, so the next key replaced it. Import VS Code keybindings maps cursorColumnSelect* and editor.action.toggleColumnSelection.
feature: Right-clicking a commit in the Source Control COMMITS graph opens its actions: Cherry-Pick, Revert, Checkout (Detached), Create Branch Here, Create Tag Here, Reset Current Branch to Here (Soft, Mixed or Hard, which asks first), Copy Commit Hash and Copy Commit Message.
