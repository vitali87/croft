feature: Ctrl+L (Cmd+L on Mac) selects the whole line the caret is on, and each further press adds the next line, as Expand Line Selection does in VS Code (also in the Command Palette).
fix: A triple-click selects the whole line instead of dropping the word the double-click had just selected, and a drag after it extends the selection line by line.
fix: A click on a line number selects that line instead of only moving the caret, and a drag down the line numbers selects whole lines.
feature: Markdown: Open Preview to the Side (`Cmd+K V` on a Markdown file, as in VS Code) renders the file in the next editor group and shows each edit as you type in the source.
fix: A Markdown preview stays rendered when its file is saved from another pane or rewritten on disk, and a split's preview shows what is typed in the source pane beside it instead of the file as last loaded.
feature: The archive browser opens `.tar.bz2` (`.tbz2`, `.tbz`) and `.tar.zst` (`.tzst`) archives, by extension or by content, where they opened as a hex dump.
feature: A calmer status bar: a teal cap with the `<>` mark and the workspace's name replaces the wordmark, the branch stays quiet with a small amber dot for uncommitted changes, problem counts stay dim at zero, the line and column numbers stand out from their labels, and the language sits in a pill with its file icon.
feature: Status bar badges (vim's mode, a macro or terminal recording, a running CodeQL query) are rounded pills, and messages name files inside the workspace by their relative path.
