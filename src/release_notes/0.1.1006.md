feature: the debugger gains VS Code's other breakpoint kinds. Ctrl+Shift+F9 puts a hit count on a breakpoint, Ctrl+F9 breaks when a named function is called, Ctrl+Alt+F9 (or right-clicking a variable) breaks when a variable changes, and Ctrl+F10 runs to the cursor's line. Each is sent only to a debug adapter that supports it; otherwise the status bar says the adapter does not.
