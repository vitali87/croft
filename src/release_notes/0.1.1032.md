fix: on Kitty-protocol terminals (Kitty, Ghostty, WezTerm with Kitty graphics), an image beside streaming terminal output is no longer resent as the text changes. Kitty keeps pictures on their own layer, so croft sends one only when it is new, moves or was cleared, which keeps an `imgcat` picture cheap over SSH.
fix: less terminal traffic with images on, which is what a slow SSH link feels. Typing no longer re-sends the minimap image on every keystroke: it catches up at most every 300 ms (8.8 KB per key down to 5.1 KB on iTerm2, 7.8 KB down to 3.6 KB on Kitty). The activity-bar icons are no longer re-sent every two seconds while idle: Kitty never needed it, and on iTerm2 it now runs only after the cells next to the icons changed (77 KB per 10 idle seconds down to 3 KB on both).
