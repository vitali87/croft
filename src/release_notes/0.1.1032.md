fix: on Kitty-protocol terminals (Kitty, Ghostty, WezTerm with Kitty graphics), an image beside streaming terminal output is no longer resent as the text changes. Kitty keeps pictures on their own layer, so croft sends one only when it is new, moves or was cleared, which keeps an `imgcat` picture cheap over SSH.
fix: less terminal traffic with images on, which is what a slow SSH link feels. Typing no longer re-sends the minimap image on every keystroke: it catches up at most every 300 ms, compressed to about a quarter of its old size (8.8 KB per key down to 3.4 KB on iTerm2, 7.8 KB down to 1.6 KB on Kitty). The activity-bar icons are no longer re-sent every two seconds while idle: Kitty never needed it, and on iTerm2 it now runs only after the cells next to the icons changed (77 KB per 10 idle seconds down to 3 KB on both).
fix: the PROBLEMS badge, the Run and Debug icon and the sidebar illustrations (no-repo Source Control, empty Remote) are no longer re-sent to the terminal after every redraw, only when they change, move, come back, or (iTerm2) the cells around them were repainted. croft also no longer clears the whole screen at start-up and on a theme switch when there were no problems to begin with.
fix: the first keystroke into a file no longer wipes and repaints the whole screen on iTerm2. The Explorer's unsaved badge appearing was mistaken for the activity icons moving.
