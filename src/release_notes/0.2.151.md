fix: Any change to a preview (italic) tab makes it a regular tab, so the next single-click on a file opens beside it instead of replacing it and losing the unsaved change. Move Line, Copy Line, Toggle Comment, Join Lines, the case transforms, Sort Lines, the trims, Transpose Characters, Convert Indentation, Cut, an undo, and a spreadsheet or hex edit all left it a preview, and a spreadsheet cell still being typed into was lost to the next single-click (#2073).
fix: Re-running a Search Editor (Cmd/Ctrl+K Shift+R) drops the old selection and extra cursors with the old results, so a word selected on a row the new results no longer have no longer crashes croft, and one undo takes the rerun back; Replace All and other whole-file rewrites drop extra cursors too (#2074).
fix: Changing indent guides, bracket-pair colours or rendered whitespace, from config.json, the Settings editor or the Command Palette, updates every open tab and every split at once, not only the tab in front (#2075).
