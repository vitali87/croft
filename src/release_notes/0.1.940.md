feature: the debug picker now follows the order your launch.json asks for. A configuration or compound that sets `presentation` is grouped and ordered by the same rules VS Code uses, and one that sets `hidden` is left out of the list and its count. Group names are compared literally rather than by language-aware collation, so names that differ only in accents may sit in a different order than VS Code puts them. A file that says nothing about presentation is listed exactly as written, as before.
