feature: answer an agent's pending edit from your phone. With a notification sink configured, each edit waiting in the approval popup sends an `approval_pending` notification with **Approve** and **Deny** buttons (ntfy action buttons, Termux notification buttons, a webhook's `actions`, or `CROFT_APPROVE_LINK` and `CROFT_DENY_LINK` for a command sink). A button runs `croft decide` on the machine where croft is open, over ssh if that is another host, and answers the agent without attaching. The link carries a random token for that one edit, which stops working once the edit is answered anywhere or its time runs out. Tapping the notification itself opens the session with the approval popup showing (`croft://attach?…&focus=approval`).
