feature: Live Run (`Cmd+K V`) re-runs a Python file every time you pause typing and shows what each line did beside it: the values assignments produced (`i = 0, 1, 2 … 9 ×10` for a loop), what a line printed, what a function returned, and the exception the run died with, on the line that raised it. Line numbers turn green for statements that ran and red for ones that never did. It runs the unsaved buffer with the project's own `.venv`, and is armed per file so no script runs unless you ask. Also in the command palette as Python: Toggle Live Run.
feature: renaming or moving a file in the Explorer now updates the imports that name it, like VS Code. croft asks the language servers for their edit before the move (`willRenameFiles`), so `mod util;` becomes `mod helpers;` when `util.rs` is renamed. A server that does not answer within two seconds never holds up the move.
feature: Types: Show Supertypes (`Cmd+K Shift+U`) and Types: Show Subtypes (`Cmd+K Shift+D`) list the classes, traits or interfaces above or below the type at the caret, from the language server's type hierarchy, in the same picker as call hierarchy.
feature: Peek References (`Alt+Shift+F12`) shows each reference to the symbol at the caret in the peek popup, "Reference 2 of 7", with `Up` / `Down` to step through them and `Enter` to jump. `Shift+F12` still opens the references picker.
feature: the Markdown preview keeps its place. It opens at the part of the document the source was showing, toggling back returns the source to where the preview was, and with source and preview side by side in a split, the other pane follows as you scroll.
feature: code lenses from the language server appear at the end of a symbol's line and run when clicked, like VS Code's: rust-analyzer's "▶ Run Test" runs the test in a terminal pane and "⚙ Debug" starts croft's debugger. `Cmd+K Shift+E` runs the caret line's lens from the keyboard, and Editor: Toggle CodeLens hides them.
feature: more breakpoint kinds, as in VS Code: hit count breakpoints (pause on the Nth hit), function breakpoints (pause on entry to a named function), Break When Value Changes on a variable of the paused frame (with adapters that support data breakpoints, such as lldb-dap), and Run to Cursor (`Ctrl+F10`), which stops once at the caret line without leaving a breakpoint behind.
feature: Search Editor, as in VS Code. `Cmd+K Shift+F` opens the Search sidebar's results as a tab you can keep, scroll and search. Edit its `# Query:` header and press `Cmd+K Shift+R` to search again, and press `Enter` on a result to open it.
feature: interactive rebase in croft. `git rebase -i` run in a croft terminal opens its plan as a tab, where `p` `r` `e` `s` `f` `d` set each commit's action and `Alt+Up` / `Alt+Down` reorder them. Save and close the tab to start the rebase, or run Rebase: Abort to abort it. `croft edit --wait <file>` is also available to any tool that wants an editor it can wait on.
feature: terminal command suggestions. As you type at a prompt, the rest of the newest matching command from croft's history appears in grey after the cursor, preferring one that succeeded in the same folder, and `Right` accepts it, as in fish. Shells that draw their own suggestions are left alone. Terminal: Toggle Command Suggestions turns them off.
feature: a Keyboard Shortcuts editor (`Cmd+K Cmd+S`, or from Settings). It lists every command with its shortcut and is searchable. Choose a command, press the new chord, and croft writes it to `keybindings.json`, keeping your comments, and it takes effect at once. Settings also gains CodeLens and Terminal Command Suggestions toggles.
feature: profiles. Profiles: Switch Profile keeps named sets of settings, keybindings and snippets (for example Python and Writing) and switches between them. A new profile starts as a copy of your current setup, and a workspace can pin its own profile in `.croft/profile`.
feature: inline AI suggestions (`Cmd+K Shift+G`). A pause in typing at the end of a line shows the model's suggested continuation as grey ghost text, `Tab` accepts it and `Esc` dismisses it. They use the workspace's local navigator model when one is seated, otherwise the Claude API with `ANTHROPIC_API_KEY`. Off by default, because turning them on sends code to the model.
feature: dev containers. `croft devcontainer [folder]` opens a folder inside the container its `.devcontainer/devcontainer.json` describes: it builds or pulls the image, mounts the folder, forwards ports, runs `postCreateCommand` once, installs croft in the container and runs it there. The next run reuses the container.
feature: screen reader mode and a translatable interface. With `screen_reader` on (Accessibility: Toggle Screen Reader Mode), the caret stops blinking and stays on the focused text, and the status bar describes each change (the line you moved to, the diagnostic under the caret, the highlighted item, focus changes), optionally spoken through `screen_reader_command`. Menus, palette titles and status messages now come from a catalog: German and Spanish ship as starters, `locale` or `LANG` picks one, and `croft locale-template <lang>` starts a new translation.
feature: write PR reviews from the editor. A reply typed into a review thread's box posts to GitHub, Review: Resolve or Unresolve Thread flips a thread, and Review: Add Comment on This Line plus Review: Submit Review send your comments as Comment, Approve or Request Changes. Comments on lines outside the diff go into the review's summary so GitHub doesn't refuse the review. Loaded threads now show their replies and whether they are resolved.
feature: Source Control: Export Comments to Pull Request posts the navigator's notes and your pending review comments as one review on the branch's PR, after a preview. The navigator's comments are marked as AI-authored (`review_ai_prefix`), and comments on lines outside the diff go into the summary.
feature: `croft://attach?host=<ssh alias>&path=<folder>&focus=terminal` links open that session, so a notification can land you in the waiting croft. `croft install-link-handler` registers them on Linux and in Termux, and the macOS launcher registers them itself. A link only reaches hosts in your `~/.ssh/config`.
fix: a language server restart that fails (after switching the workspace root) now reports in the status bar and the OUTPUT panel instead of writing to the terminal under croft, where the text stayed on screen.
fix: with two local windows on one remote session, a link click, port forward, clipboard or file pull ran once per window (one browser tab each). Each request is now handled by exactly one window.
feature: sticky notes (`Cmd+K N`). Leave a note on a line, and in a `--solo` session every participant sees it under the same line. It follows the line as code moves, takes replies in its box, and resolves from its ✕. `F4` walks unresolved notes, the Explorer shows how many each file has, notes survive disconnects and restarts, and Export Comments to Pull Request posts them. Alone, they are personal notes.
