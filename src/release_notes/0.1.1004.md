feature: a compound debug session's background members are no longer invisible. Their program output reaches the debug console, tagged with the member's name. A member that stops at a breakpoint while the one you are watching is running takes the view, as in VS Code; if you are already inspecting a stop, the status line names the member that stopped instead. `Cmd+Opt+Shift+G` (and Debug: Switch Session in the command palette) moves to the next member, and whatever it did in the background replays when you get there.
