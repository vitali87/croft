feature: In pull request review, `c` checks the PR's head out into a worktree beside the repository and adds it to the workspace, so the changed code has go-to-definition, hover and tests. Pressing `c` again after a new push moves the checkout to it, but never away from commits you made there.
feature: Leaving review with Esc removes a checkout review mode created. It is kept, and the status says why, when it has edits, build output, new commits or an unsaved tab, or when the worktree existed before review.
