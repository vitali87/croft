feature: `files_associations` (VS Code's `files.associations`) picks the language a file opens in by glob, in user or workspace config: `{ "*.tpl": "html", "**/templates/*.txt": "html" }`. The highlighter and the language server both follow it, open tabs switch when it changes (unless their language was picked by hand), and `croft import-vscode` and a repo's `.vscode/settings.json` carry `files.associations` over.
