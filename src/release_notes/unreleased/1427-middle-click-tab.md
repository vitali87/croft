fix: A middle-click on a tab now closes that tab, as in VS Code and browsers, asking first if it has unsaved edits; the tab you are working in stays active. A tab command bound to a gesture in the tab strip (`close_editor`, `close_other_editors`, `close_editors_to_the_right`, `keep_editor`) now acts on the tab you clicked. Before, a middle-click on a tab did nothing, and binding it to `close_editor` closed the active tab instead of the clicked one.
