fix: A repository whose `.vscode/settings.json` turns on `editor.formatOnSave` and names an `editor.defaultFormatter` croft does not run (Biome, Prettier) no longer has its files reformatted by the language server on save: croft saves them as typed and says once which formatter the project uses. `editor.defaultFormatter`, globally or in a `"[language]"` block, now maps into croft settings.
