feature: File: New Untitled Text File (`Ctrl+N`, `Cmd+N` on macOS, from the editor or the side bar) opens a focused `Untitled-1` tab with no file behind it, for pasting a log or drafting a message; the next is `Untitled-2`. Saving it asks where to write it (Save As), and the tab then takes that name and language. Quitting with text in one asks first, and VS Code's `workbench.action.files.newUntitledFile` keybinding imports onto it.
