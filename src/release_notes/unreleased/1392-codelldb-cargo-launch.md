feature: Rust launch.json configs from CodeLLDB (`"cargo": { "args": ["build", …], "filter": … }` with no `program`) now debug: croft runs that cargo build (`test` builds with `--no-run`) in the background, picks the executable the filter names from cargo's JSON output, and launches it under lldb-dap. A failed build, or a filter matching no executable or several, stops the launch and says why.
