fix: Language server errors, questions and links now reach you. An error or warning a server sends, such as rust-analyzer's "Failed to load workspaces" for a broken Cargo.toml, shows on the status line instead of only in OUTPUT. A server's question opens a picker of its answers (Esc answers none), and a document or link it asks to show opens in a tab or the browser, so gopls's "Browse documentation" quick fixes now open the page. A quick fix that only runs a server command now says "Ran …" rather than "Applied quick fix".
