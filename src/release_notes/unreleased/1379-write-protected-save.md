fix: A file you can't write shows a lock on its tab and "Read-only" in the status bar as soon as it opens. Saving your own write-protected (`chmod 444`) file now asks first, and a second Cmd+S overwrites it and puts its permissions back. When a save fails with "permission denied", the next Cmd+S (or File: Save with Sudo) writes the file through `sudo tee` in a terminal pane, where sudo asks for your password, and the tab turns clean once the file is written.
