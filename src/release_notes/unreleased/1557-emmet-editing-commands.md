feature: Emmet can now edit markup already written, as in VS Code: **Emmet: Wrap with Abbreviation** wraps the selected lines (or the element around the cursor) in an abbreviation such as `nav.menu`, with `ul>li*` putting each line in its own `li`; **Remove Tag** takes away the tags around the cursor and moves their content out a level; **Update Tag** renames both tags; **Go to Matching Pair** jumps between an opening and closing tag; and **Balance (outward/inward)** grows or shrinks the selection one element at a time. Imported VS Code keybindings for these commands map across (#1557).
