feature: The Markdown preview renders math. `$…$` and `$$…$$` show as readable symbols instead of raw TeX: `$e^{i\pi}$` reads `e^(iπ)`, `\sum_{k=1}^{n}` reads `∑ₖ₌₁ⁿ`, `\frac{a}{b}` reads `a/b`, with Greek letters, operators, arrows and `\mathbb{R}` as their Unicode characters. A `$$` block keeps its own line, one per `\\` row, instead of running into the paragraph. A command croft doesn't know stays as TeX, and a `$5 and $10` price stays as typed.
