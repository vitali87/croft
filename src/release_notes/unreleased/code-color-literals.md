feat: A colour constructor in code is tinted with its own colour, like `#rrggbb` and `rgb()` already are: `Color::Rgb(0xeb, 0xcb, 0x8b)`, `Rgb(235, 203, 139)`, `Color::from_rgb(..)`, the alpha forms (`Rgba(..)`, `from_rgba_unmultiplied(..)`) and the `image` crate's array form `Rgba([0xe9, 0x7c, 0x41, 0xff])`, with decimal or `0x` integers. Big files get it too: past the size limit of the whole-file scan, the visible lines are scanned as they are drawn.
