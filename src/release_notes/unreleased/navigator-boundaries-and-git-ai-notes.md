feature: The navigator's proactive comments wait for a workflow boundary — a commit, a test run you started, or a task run ending — instead of firing on a typing pause, so they arrive when you are reviewing rather than mid-task, and a look you have typed past is dropped.
feature: A commit you make in croft that carries lines the navigator wrote gets a Git AI authorship note on `refs/notes/ai`, naming the navigator's lines and yours, so `git-ai blame` and `git notes --ref=ai show` still know who wrote what after the commit; lines croft did not see written are left out, and `disable_git_ai_notes` turns it off.
