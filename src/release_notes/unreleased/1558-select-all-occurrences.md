feature: Select All Occurrences and Add Cursors to Line Ends, as in VS Code: `Cmd+Shift+L` (`Ctrl+Shift+L` on Linux) puts a cursor on every occurrence of the selection or the word under the cursor at once, and `Shift+Alt+I` puts one at the end of every selected line, so a block of lines can be edited together. Both are in the Command Palette, and VS Code's `selectHighlights` and `insertCursorAtEndOfEachLineSelected` keybindings import onto them. `Cmd+D` from a selection you made now matches it as text, inside longer words too, as VS Code does; from a bare caret it still takes whole words.
