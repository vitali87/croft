feature: Ctrl+Space now completes from the words already in your open documents when no language server has suggestions, as VS Code does: a Makefile variable, a `.env` key or a word in a note is offered on its next use. A file with a server still gets only the server's list, unless it has nothing to offer. The `word_based_suggestions` setting (imported from `editor.wordBasedSuggestions`) picks the current document, open documents of the same language (the default), all open documents, or off.
