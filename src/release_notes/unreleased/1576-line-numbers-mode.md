feature: Line numbers can be relative, every tenth line or off, as VS Code's `editor.lineNumbers` offers: set `line_numbers` to `relative`, `interval` or `off`, or cycle them with "View: Change Line Numbers" in the Command Palette. Relative numbers show each line's distance from the caret, counting a folded block as one line, so Vim counts such as `5j` and `3dd` can be read off the gutter. The caret's line number is now brighter than the rest. VS Code's `editor.lineNumbers` is carried over by `.vscode/settings.json` and `croft import-vscode`.
