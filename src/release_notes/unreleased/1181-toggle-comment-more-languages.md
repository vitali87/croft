fix: Ctrl+/ (Toggle Line Comment) now works in HTML, CSS, Markdown and XML (wrapping the lines in a block comment), in JSON with `//`, and in files croft has no grammar for but whose comment it knows by name or extension (Kotlin, Swift, PHP, .gitignore, .env, Haskell, .ini, LaTeX and more). Where a file has no comment at all, the key now says so in the status bar instead of doing nothing.
