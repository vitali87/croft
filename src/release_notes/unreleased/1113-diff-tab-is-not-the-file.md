fix: Rename Symbol, quick fixes and Format Document no longer skip a file whose Source Control diff or Explorer compare is open. The edits used to go to the diff, which changed nothing, and the file was neither edited nor written. With the editor split, they now edit the file's tab in whichever group holds it, instead of rewriting the file on disk under that tab's unsaved changes. Opening that file (Quick Open, the Explorer, a problem row) now opens the file beside its diff instead of landing on the diff.
