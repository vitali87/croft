feature: The terminal's actions are now commands: Terminal: Clear, Rename, Kill the Active Terminal Instance, Split Terminal, Create New Terminal (With Profile), Quick Select, Enter Copy Mode, Show Command History and Open Scrollback in Editor are in the Command Palette and can be bound in `keybindings.json`, where a chord for a terminal command works with the terminal focused and shows in the pane's right-click menu. `croft import-vscode` now carries over VS Code's terminal clear, rename, kill, split and new-with-profile chords.
