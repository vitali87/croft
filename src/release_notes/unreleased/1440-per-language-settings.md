feature: VS Code's language-specific settings now work: a `"[python]": { "editor.formatOnSave": true }` block in a repo's `.vscode/settings.json` formats Python on save, and croft's own `languages` setting overrides format on save, format on type, whitespace rendering, inlay hints and auto-closing pairs per language. `croft import-vscode` maps these blocks instead of listing them as unknown, and names the keys inside them it cannot honour.
