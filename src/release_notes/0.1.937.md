fix: opening a home directory no longer pins two CPU cores. The file watcher resolved the workspace root through `canonicalize` for every path of every filesystem event, on every frame — one failing `readlink` per path component each time — which held ~210% CPU indefinitely on a `$HOME` workspace. The root is now resolved once per bind.
fix: the .NET, Dart and Go toolchain caches (`.nuget`, `.pub-cache`, `.dart-tool`, `.dotnet`, `go/pkg/mod`) and oh-my-zsh's plugin tree are treated as noise like `.cargo` and `.npm` already were, so a home-dir workspace stops indexing and watching tens of thousands of files it can never open. A project's own `go/` source directory is still indexed.
fix: the workspace folder you opened no longer looks empty to the watcher when its own path sits under a `build/`, `dist/` or `target/` ancestor. Filesystem events were classified by their whole absolute path, so the ancestor's name made every file in the workspace read as build noise: external edits never reached the agent-lane ledger and the Cmd+P index never rebuilt. Noise is now measured relative to the workspace root, as the watch-target walk already did.
fix: a workspace opened at `~/go` prunes its own `pkg/mod` module cache again. Measuring a cache run relative to the root dropped any run that straddled it, and GOPATH's cache is exactly that shape: the run's first component is the root's own last one, so a `~/go` workspace walked and watched all 1,357 cache directories.
