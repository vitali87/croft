fix: opening a home directory no longer pins two CPU cores. The file watcher resolved the workspace root through `canonicalize` for every path of every filesystem event, on every frame — one failing `readlink` per path component each time — which held ~210% CPU indefinitely on a `$HOME` workspace. The root is now resolved once per bind.
fix: the .NET, Dart and Go toolchain caches (`.nuget`, `.pub-cache`, `.dart-tool`, `.dotnet`, `go/pkg/mod`) and oh-my-zsh's plugin tree are treated as noise like `.cargo` and `.npm` already were, so a home-dir workspace stops indexing and watching tens of thousands of files it can never open. A project's own `go/` source directory is still indexed.
fix: a workspace whose own path sits under a `build/`, `dist/` or `target/` ancestor no longer looks empty to the watcher. Filesystem events were classified by their whole absolute path, so the ancestor's name made every file in the workspace read as build noise: external edits never reached the agent-lane ledger and the Cmd+P index never rebuilt. Noise is now measured relative to the workspace root, as the watch-target walk already did.
