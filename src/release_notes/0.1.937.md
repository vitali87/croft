fix: opening a home directory no longer pins two CPU cores. The file watcher resolved the workspace root through `canonicalize` for every path of every filesystem event, on every frame — one failing `readlink` per path component each time — which held ~210% CPU indefinitely on a `$HOME` workspace. The root is now resolved once per bind.
fix: the .NET, Dart and Go toolchain caches (`.nuget`, `.pub-cache`, `.dart-tool`, `.dotnet`, `go/pkg/mod`) and oh-my-zsh's plugin tree are treated as noise like `.cargo` and `.npm` already were, so a home-dir workspace stops indexing and watching tens of thousands of files it can never open. The module cache is pruned wherever it sits relative to the folder you opened, `~/go` included. A project's own `go/` source directory is still indexed.
fix: a workspace folder no longer looks empty to the watcher when its own path sits under a `build/`, `dist/` or `target/` ancestor. Filesystem events were classified by their whole absolute path, so the ancestor's name made every file in the folder read as build noise: external edits never reached the agent-lane ledger and the Cmd+P index never rebuilt. Noise is now measured relative to the workspace root that owns the path, for secondary folders in a multi-root workspace as well as the one you launched.
