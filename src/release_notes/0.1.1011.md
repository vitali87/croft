fix: an image, PDF page, Markdown picture or minimap no longer stalls croft over SSH. croft re-sent the whole picture (often megabytes) on every redraw, a keystroke or a cursor blink, which a local terminal absorbs but a remote link cannot. It is now sent once and again only when something covered, moved or wiped it: opening an 880 KB PNG and pressing 20 keys went from 35 MB of output to 63 KB.
