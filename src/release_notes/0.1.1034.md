fix: submitting a pull-request review no longer drops comments added while it was in flight, and a second submit (or Post comments) is refused until the first finishes, instead of posting the review twice.
fix: Live Run kills everything a script started when it runs out of time, not just the interpreter, so a script that spawns a server or a subprocess no longer leaves one behind on every re-run. A large buffer can no longer hang a run past its time limit.
fix: sticky notes are saved by writing aside and renaming, so a crash mid-save no longer loses every note in the workspace. A note now finds its line anywhere in the file, not only within 200 lines, and a note made after a restart can no longer reuse an old note's id.
fix: a `croft://` link to a `~/` path opens that folder in your home directory, locally and over SSH, instead of a folder literally named `~`.
