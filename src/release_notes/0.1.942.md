feature: a launch.json compound now runs. Selecting one starts every configuration it names, in the order the file lists them, and croft tells you which sessions are live and which one you are looking at. Stopping stops all of them; one member ending leaves the rest running, and one that fails to start no longer takes its siblings down. A member that declares its own preLaunchTask is not started, and is named, rather than being debugged against whatever the last build left behind.
