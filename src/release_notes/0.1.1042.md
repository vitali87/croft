fix: regex Replace All in the search panel no longer matches across line breaks. A pattern like `a[^;]*` or `foo\s+` could delete lines that the search results never showed. Matching now works line by line, the same as the search.
fix: whole-word Replace All replaces matches that start or end with punctuation, such as `$var`, `-flag` or `@decorator`. It used to find nothing to replace even though the search listed them.
fix: Replace All writes each file safely, so a failed write (for example on a full disk) no longer leaves the file truncated, and it keeps the file's permissions. Files it could not rewrite, such as files that are not UTF-8, are now named in the status instead of silently skipped.
fix: creating a file in the Explorer, or opening a settings or snippets file, opens it in its own tab. It used to replace the current tab and throw away its unsaved edits.
fix: moving a file or folder to the Trash no longer closes a tab with unsaved changes. Clean tabs of the deleted files close in every split, including files inside a deleted folder.
fix: renaming or moving a file in the Explorer updates its tabs in every split, not just the focused one.
fix: choosing Reload in the external-change prompt reloads files open in other splits too.
fix: pasting from the clipboard on Wayland no longer adds a trailing newline, and never pastes an image's bytes as text. A clipboard program that doesn't respond no longer freezes croft; it gives up after 2 seconds.
fix: renaming a file to a different case of the same name (for example `readme.md` to `README.md`) works on macOS.
security: croft's saved workspace and terminal-session files, which include recent terminal output, are now readable only by you.
