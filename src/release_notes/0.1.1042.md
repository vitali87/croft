fix: terminal rewind memory is one budget shared by all panes (256 MB, or 64 MB on a remote host) instead of 64 MB for each pane, and its screen snapshots now count toward it. Set it with `terminal_rewind_mb` in `config.json`; `0` turns rewind off. A closed pane frees its share at once.
fix: when a remote update has to compile croft on the host, it uses one compile job on machines with less than 16 GB of RAM, runs under a memory limit where systemd allows it, and stops croft's language servers until the build finishes. Before, the build and rust-analyzer together could use up the host's memory, and the kernel then killed croft or a terminal pane.
feature: the F8 performance readout shows croft's memory use and how much of the rewind budget is in use.
